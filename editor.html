イベント一覧

📖 使い方

「+ 追加」でイベントを作り、シーン(セリフ)を並べていきます。書き出したJSONは、ゲーム本体の「設定 → 追加シナリオを読み込む」で遊べます。

イベントの起こり方

プレイヤーが場所を訪れたとき、条件を満たすイベントのうち優先度が最も高いものが起こります(同率はランダム)。内蔵の物語イベントは優先度10前後、雑談は1〜3です。

条件

○日目以降・時間帯・好感度・フラグを組み合わせられます。フラグは効果欄「フラグON」で立てた合言葉です。プロローグ済みの印は prologue。

シーンの流れ

上から順に再生されます。ジャンプ先は「次に飛ぶシーン番号」(0始まり)。選択肢で分岐した先の合流にも使います。空欄なら次のシーンへ。

話者

ナレーション / 主人公 / レオ / ティエラ / ウェイン / ロムド / ハオシェン / ニノン / 島の人。本文の {name} は主人公名に置き換わります。

・ティエラ: 一人称「私」。敬語を使わない。「〜だよ」「〜だね」
